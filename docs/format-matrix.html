How this was run

tools/fetch_web_samples.py downloads the samples; tools/format_matrix.py imports them; tools/render_service_shots.py adds a camera layer per file and submits it to POST /render. The service adds its own lighting. Renders are 960 × 540.

Reading the results

  • A failure here is a result for that one sample, not for the whole format.
  • The .ifczip sample was zipped locally from the IFC sample.
  • No public samples were found for ACIS binary .sab or Solid Edge .pwd.
  • Sample files come from public repositories with their own licences.
